# scratch-launcher

Scratch Launcher is a basic launcher for Scratch games that lets you download and launch Scratch games from their source code quickly
and easily, with offline support, a small runtime, and more.

Each game can have its own TurboWarp runtime settings. Use the Settings button in the launcher UI and the app will save those values
to a JSON file next to the .sb3 with the same base name (for example, My Game.sb3 and My Game.json).

## Download and Install

Go to the GitHub Releases page and download the newest installer or executable for your platform. Download and run the installer or
packaged file and the launcher should start.

## Manually Adding New Games

If you want to manually add new games to the launcher, find the location of the app's executable, where there should be a folder called
"games". Drop a .sb3 file in this folder and it should be automatically detected by the app.
